# Pine Station

Интерактивный 3D-этюд лесной придорожной станции по предоставленному изображению.

## Открыть

Онлайн: https://vdenis.github.io/pine-station/ · AR: https://vdenis.github.io/pine-station/ar.html

Локально из этой папки:

```sh
python3 -m http.server 4173 --directory dist
```

Затем открыть http://localhost:4173. Зависимости для просмотра устанавливать не требуется: Three.js находится в `dist/vendor/`. Страница должна открываться через HTTP-сервер, а не двойным щелчком по HTML.

## Управление

- Обзор: потянуть мышью — вращение; колесо — приближение; правая кнопка — сдвиг.
- Кнопки 01–04 и клавиши 1–4 переключают ракурсы.
- Прогулка: WASD или стрелки; Shift — быстрее. Нажать на сцену для захвата мыши, Esc — отпустить. При недоступном захвате удерживать кнопку мыши и тянуть.
- На телефоне: перетаскивание для поворота и экранные стрелки для движения.
- Кнопка солнца: высота солнца, отражения и экспорт GLB.
- Кнопка «AR» открывает страницу дополненной реальности: станция ставится на любую поверхность через Google Scene Viewer. Нужен Android с Google Play Services for AR; страница должна открываться с телефона по HTTPS.
- Референс открывается отдельным окном.
- Кнопка «Автомобили» открывает отдельные крупные планы Tesla Model X, Audi RS Q8 и Mercedes-Benz G-Class.

## Файлы

- `dist/ar.html` — AR-лендинг для Google Scene Viewer; адрес модели вычисляет сам, поэтому работает на любом HTTPS-хостинге без правок.
- `dist/scene.js` — геометрия, освещение, материалы и управление.
- `dist/vehicles.js` — три авторские модели автомобилей по фото: Tesla Model X, Audi RS Q8 и Mercedes-Benz G-Class. Кузова, эмблемы, оптика, колёса и детали выполнены геометрией.
- `dist/style.css` — адаптивный интерфейс.
- `dist/assets/pine-station.glb` — готовая переносимая 3D-модель (28.7 MB).
- `dist/assets/reference.png` — предоставленный референс.

Единицы модели приблизительно соответствуют метрам, ось Y направлена вверх. Это стилизованная реконструкция: точные размеры и скрытые части интерпретированы. Автомобили смоделированы по визуальному референсу, это не заводские CAD-модели. Кафе предназначено для осмотра снаружи. Браузерное небо и зеркальное покрытие реализованы шейдерами; GLB содержит геометрию и стандартные материалы, но эти эффекты требуют настройки в целевом редакторе.

Для рендера нужен браузер с WebGL 2. Геометрия сгруппирована по материалам для быстрого перемещения. Three.js распространяется по лицензии MIT, см. `dist/vendor/LICENSE`.

## Android AR (V4)

Открыть https://vdenis.github.io/pine-station/ar.html?v=4 в отдельной вкладке Chrome. На Android нажать «Поставить в комнате · Android AR»: обычная ссылка запускает Google Scene Viewer через приложение Google. Резервный вариант — «AR в браузере» внутри модели (WebXR). Нужны обновлённые Google и Google Play Services for AR. Для WebXR разрешите камеру и AR в настройках сайта.

AR использует отдельный `dist/assets/pine-station-ar.glb`: около 2,4 МБ, 65 тысяч треугольников, ширина макета 90 см, масштабирование разрешено. Полная модель и интерактивная сцена сохраняются отдельно. У AR-макета удалены дальние горы, огромный ландшафт, источники света и расширения материалов, не поддерживаемые Scene Viewer; текстуры уменьшены, геометрия упрощена. Основные здания и все три автомобиля сохранены. Метрики — `dist/assets/ar-model-info.json`.

Пересобрать после обновления полной модели: `npm ci && npm run build:ar`. Проверить формат, размеры, геометрию, автомобили и ссылки запуска: `npm test`. Проверка на компьютере не заменяет проверку камеры и ARCore на физическом Android-телефоне.

Требования и формат Android-ссылок: https://developers.google.com/ar/develop/scene-viewer
